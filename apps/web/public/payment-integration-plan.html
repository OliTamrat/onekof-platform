1 Executive Summary

This document presents the payment system integration architecture for the Onekof Platform, a multi-tenant project management system developed by DAPS Analytics PLC. The payment system is designed to serve Ethiopian organizations across government, private, NGO, and educational sectors with a security-first approach aligned to INSA compliance standards.

ⓘ
Current Status: The platform's subscription data model, pricing tiers, billing terms, and multi-currency support are fully implemented in the database schema and user interface. Payment gateway integrations are architecturally planned with security controls defined in advance of activation, ensuring no payment processing occurs without full INSA-compliant audit controls in place.

Key Design Principles

  • No direct card handling - All payment credentials are processed by PCI DSS-certified third-party gateways; Onekof never stores, processes, or transmits raw card numbers
  • Ethiopian payment-first - Chapa (aggregator for Telebirr, CBE Birr, Amole, bank transfers) as the primary domestic gateway
  • Multi-currency support - ETB for domestic customers, USD/EUR/GBP for international, with currency defined at the organization level
  • Tiered deployment alignment - Payment routing respects the platform's 3-tier hosting model (EthioTelecom Cloud, On-Premise, Global Cloud)
  • Auditable by design - Every payment event is logged with immutable audit trails, webhook signature verification, and idempotent processing

4 Payment Processing Flow

4.1 Subscription Checkout Flow

User Selects Plan

Organization admin selects a subscription tier from the pricing modal. The client sends a plan upgrade request to our API with the organization ID and selected plan.

Gateway Router Determines Provider

Based on the organization's hostingTier and preferred currency, the payment service routes to Chapa (ETB) or Stripe (USD/EUR). Government orgs on EthioTelecom Cloud are always routed domestically.

Hosted Checkout Page

The user is redirected to a gateway-hosted checkout page (Chapa Checkout or Stripe Checkout). Onekof never handles raw payment credentials - the gateway manages PCI-scoped input collection.

Payment Confirmation via Webhook

The gateway sends a signed webhook to our /api/webhooks/payment endpoint. The signature is verified using HMAC-SHA256 before any processing. Idempotency keys prevent duplicate processing.

Subscription Activation

Upon verified payment, the system updates the organization's plan, status, subscriptionId, currentPeriodEnd, and adjusts resource limits.

Audit Log & Notification

A payment event is written to the immutable audit log with transaction ID, amount, currency, gateway, timestamp, and IP. A confirmation email is sent to the organization's billingEmail.

5 Security Architecture

🔒
Core Principle: Onekof is designed as a PCI DSS-exempt merchant. We never store, process, or transmit cardholder data. All payment credential handling is delegated to PCI DSS Level 1-certified gateways (Stripe) and NBE-licensed processors (Chapa). This eliminates the most critical attack surface for payment systems.

6 Deployment Tier Payment Routing

Onekof supports three hosting tiers, each with specific payment routing requirements that respect data sovereignty and organizational policy:

🏢
Tier 1: EthioTelecom Cloud (Government)
GOV_ETHIOTELECOM hosting tier
  • Payment Gateway: Chapa only (ETB) - all financial data stays within Ethiopian infrastructure
  • Methods: Telebirr, CBE Birr, Direct Bank Transfer, Government Purchase Order
  • Billing Model: Annual invoicing with Purchase Order support for government procurement
  • Data Residency: All transaction records stored on Ethiopian sovereign cloud
🏗
Tier 2: Private On-Premise
PRIVATE_ONPREM hosting tier
  • Payment Gateway: Chapa (ETB) or offline invoice for air-gapped deployments
  • Methods: Bank Transfer, Telebirr, Manual Invoice
  • Billing Model: Annual licensing with optional monthly add-ons
  • Special: License key validation for offline deployments
☁
Tier 3: Global Cloud (Vercel + Supabase)
GLOBAL_CLOUD hosting tier
  • Payment Gateway: Chapa (ETB domestic) + Stripe (USD/EUR international) - auto-routed by currency
  • Methods: All digital methods (mobile money, cards, wallets, bank transfer)
  • Billing Model: Monthly or annual subscriptions with auto-renewal
  • Self-Service: Full customer portal for payment method management, invoices, and plan changes
