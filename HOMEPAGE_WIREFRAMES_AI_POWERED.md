# Onekof Homepage - AI-Powered Wireframe Designs

**Date**: March 1, 2026
**Goal**: Make AI features VISIBLE, INTERACTIVE, and BELIEVABLE
**Design System**: SF Pro, Blue (#0EA5E9), Clean & Professional

---

## 🎨 DESIGN PRINCIPLES

1. **Show, Don't Tell** - Live demos, not screenshots
2. **Concrete, Not Abstract** - "Saves 28 hours/month" not "Saves time"
3. **Interactive, Not Passive** - Visitors try AI before signing up
4. **Proof, Not Promises** - Real customer data, real companies
5. **SF Pro Font** - Keep current typography (professional, clean)

### 1. Live AI Demo Widget (Hero Section)
```javascript
// Pseudocode
const AIDemo = () => {
  const [input, setInput] = useState('');
  const [tasks, setTasks] = useState([]);
  const [loading, setLoading] = useState(false);

  const generateTasks = async () => {
    setLoading(true);
    const response = await fetch('/api/ai/generate-tasks', {
      method: 'POST',
      body: JSON.stringify({ feature: input })
    });
    const data = await response.json();
    setTasks(data.tasks);
    setLoading(false);
  };

  return (
    <div>
      <input
        value={input}
        onChange={(e) => setInput(e.target.value)}
        placeholder="E.g., Build user authentication"
      />
      <button onClick={generateTasks}>
        🤖 Generate Tasks ✨
      </button>
      {loading && <Spinner />}
      {tasks.map(task => (
        <TaskCard key={task.id} {...task} />
      ))}
    </div>
  );
};
```
