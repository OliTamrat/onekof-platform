# EIPA Filing Master Checklist

## Software Copyright Filing
- [ ] Completed Form C-1 Application (`01_Software_Copyright/Form_C-1_Application.md`)
- [ ] Two copies of source code prepared (first & last 25 pages, or full if under 50 pages)
- [ ] Software functionality description completed (`01_Software_Copyright/Software_Description.md`)
- [ ] Date of first publication recorded (`01_Software_Copyright/Publication_Date.md`)
- [ ] Filing fee paid (check current EIPA fee schedule)
- [ ] Submitted to EIPA

## Patent / Utility Model Filing
- [ ] Completed Form P-1 Application (`02_Patent_Utility_Model/Form_P-1_Application.md`)
- [ ] Technical description with claims completed (`02_Patent_Utility_Model/Technical_Description.md`)
- [ ] Abstract written (max 150 words) (`02_Patent_Utility_Model/Abstract.md`)
- [ ] Drawings/flowcharts prepared (if applicable)
- [ ] Priority claim documented (if applicable) (`02_Patent_Utility_Model/Priority_Claim.md`)
- [ ] Filing fee paid (check current EIPA fee schedule)
- [ ] Submitted to EIPA

## Trademark Filing
- [ ] Completed Form TM-1 Application (`03_Trademark/Form_TM-1_Application.md`)
- [ ] Logo/wordmark specimens prepared (`03_Trademark/Logo_Specimens/`)
- [ ] Goods/services classified under Nice Classification (`03_Trademark/Goods_Services_Classification.md`)
- [ ] Filing fee paid (check current EIPA fee schedule)
- [ ] Submitted to EIPA
