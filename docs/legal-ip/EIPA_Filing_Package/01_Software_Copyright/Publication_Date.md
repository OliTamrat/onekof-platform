## Definition of "Publication" for Software
Under Ethiopian IP law, "publication" for software means the date when the software
was first made available to the public, which may include:

- First deployment to a publicly accessible server
- First distribution of copies to users
- First commercial offering or sale

## Evidence of Publication Date

- [ ] Git commit history showing development timeline
