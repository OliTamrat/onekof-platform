# EIPA Filing Package - OneKof Platform

## Overview
This folder contains all required templates and documents for filing Intellectual Property
with the Ethiopian Intellectual Property Authority (EIPA).

## Folder Structure

```
EIPA_Filing_Package/
├── README.md                          (this file)
├── CHECKLIST.md                       (master checklist for all filings)
├── 01_Software_Copyright/
│   ├── Form_C-1_Application.md        (completed application form)
│   ├── Source_Code_Deposit.md         (instructions for source code copies)
│   ├── Software_Description.md        (description of software functionality)
│   └── Publication_Date.md            (date of first publication record)
├── 02_Patent_Utility_Model/
│   ├── Form_P-1_Application.md        (patent application form)
│   ├── Technical_Description.md       (detailed technical description with claims)
│   ├── Abstract.md                    (abstract, max 150 words)
│   ├── Drawings_Flowcharts/           (place diagrams here)
│   └── Priority_Claim.md             (priority claim if applicable)
└── 03_Trademark/
    ├── Form_TM-1_Application.md       (trademark application form)
    ├── Logo_Specimens/                (place logo/wordmark files here)
    └── Goods_Services_Classification.md (Nice Classification list)
```

## Filing Order (Recommended)
1. **Software Copyright** - fastest to file, immediate protection
2. **Trademark** - protects the OneKof brand
3. **Patent/Utility Model** - longest process, strongest protection
