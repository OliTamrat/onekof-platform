4. Platform Architecture

Onekof runs as a self-contained Docker stack. Only the Caddy reverse proxy is exposed to the internet — the database and cache are on an internal Docker network, not accessible externally.

5. Security Posture

  • 49 security tests passed — authentication, authorization, session management, input validation, API security, data protection, audit logging
  • AES-256-GCM encryption for all uploaded files at rest
  • Role-based access control with cross-tenant isolation (OWNER, ADMIN, MEMBER, GUEST)
  • Scrypt password hashing with timing-safe comparison
  • Rate limiting on authentication, billing, and admin endpoints
  • Append-only audit logs for organization, budget, and admin actions
  • Automated backups — daily pg_dump at 03:00 EAT, 7-day retention
