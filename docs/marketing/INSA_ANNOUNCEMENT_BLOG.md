*July 2026 | DAPS Analytics*

Today we're proud to announce that **Onekof PM** has received official certification from the **Information Network Security Administration (INSA)** — Ethiopia's national cybersecurity authority.

This makes Onekof the **first project management platform** to pass INSA's rigorous 49-test Web Application Assessment, qualifying it for deployment in Ethiopian government agencies, telecom infrastructure, and regulated industries.

## What is INSA Certification?

INSA (Information Network Security Administration) is Ethiopia's national cybersecurity agency responsible for ensuring that software products deployed in critical national infrastructure meet stringent security standards.

The certification process includes:

- **Level 1 Review** — Software Requirements Specification assessment
- **Level 2 Review** — Architecture, technical design, and user documentation evaluation
- **Engagement Phase** — 49 security test cases covering authentication, authorization, session management, input validation, API security, data protection, and audit logging

Only three security findings were identified during the engagement — all fixed and verified within 24 hours.

## Why This Matters for Ethiopian Organizations

Until now, Ethiopian organizations faced a difficult choice:

1. **Use international tools** (Jira, Monday.com, Asana) that don't support Ethiopian calendars, Amharic, or ETB payments — and can't pass INSA certification for government use
2. **Use spreadsheets and WhatsApp** — flexible but impossible to scale, audit, or report from

Onekof eliminates this tradeoff.
